# Retail Banking Transaction Analysis

## Project Overview

This project analyzes retail banking data to understand customer profiles, account usage, transaction patterns, loan performance, and card usage.

The analysis was performed using MySQL and focuses on extracting meaningful business insights from banking transaction data.

## Objectives

- Customer Profile and Segmentation
- Account Usage and Branch Activity
- Transaction Patterns
- Loan Performance and Repayment Behaviour
- Card Usage and Product Engagement

## Database Tables

The project contains the following tables:

- customers
- accounts
- branches
- loans
- loan_payments
- cards
- transactions

## Tools Used

- MySQL
- MySQL Workbench
- SQL
